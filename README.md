# KVM Bridge

Share one keyboard and mouse, the clipboard and files between computers on the
same network, with end-to-end encryption.

| Folder               | Platform                                              |
|----------------------|-------------------------------------------------------|
| [`Linux`](Linux)     | Ubuntu, Fedora and other Linux systems with Wayland (GNOME, KDE Plasma) |
| `Windows`            | In progress                                           |

See [Linux/README.md](Linux/README.md) for installing, using and building
KVM Bridge.
